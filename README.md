# Proyecto M1 FT76 - Colorfly Studio

Generador de paletas de colores interactivo. Proyecto del modulo 1 del bootcamp

## Tecnologias
- HTML semantico
- CSS3 (Flexbox, Grid, variables y colores HSL - HEX)

## Como usar
- Descargar la carpeta del proyecto  o ir al link de GitHub Pages
- Abrir el archivo index.html
- Seleciona entre modo oscuro o claro segun tu preferencia ![alt text](./assets/img/image-7.png)
- Click en el boton generar paleta para ir a la seccion de generacion![alt text](./assets/img/image.png)
- Con el boton generar ![alt text](./assets/img/image-1.png) se genera una paleta aleatoria de colores
- Puedes elegir el tamaño de la paleta ![alt text](./assets/img/image-2.png)
- Puedes cambiar el nombre del color de HSL a HEX y viceversa ![alt text](./assets/img/image-3.png)
- Tambien puedes bloquear uno o varios colores para que no se cambien cuando generes una nueva paleta![alt text](./assets/img/image-4.png)
- Puedes copiar el codigo del color dependiendo de tu selecion ya sea HLS o HEX![alt text](./assets/img/image-5.png)
- Guarda tus paletas favoritas con el boton guardar ![alt text](./assets/img/image-6.png)
- Para abrir tus paletas guardadas solo haz click en la imagen![alt text](./assets/img/image-8.png)
- Para eliminarlas, haz click en eliminar ![alt text](./assets/img/image-9.png)
