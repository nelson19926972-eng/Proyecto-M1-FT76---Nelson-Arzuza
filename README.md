# Proyecto M1 FT76 - Colorfly Studio

Generador de paletas de colores interactivo. Proyecto del modulo 1 del bootcamp

## Tecnologias
- HTML semantico
- CSS3 (Flexbox, Grid, variables y colores HSL - HEX)

## Como usar
Abrir el 'index.html' en el navegador, hacer clik en el boton "generar" para crear los colores aleatorios y selecionar la cantidad de colores que quieres crear
